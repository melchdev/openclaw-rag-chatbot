# Demo RAG básico para OpenClaw

Notebook listo para Colab con documentos de ejemplo, chunking, embeddings multilingües, ranking coseno, respuesta con fuentes y evaluación Hit@3. Incluye generación de una skill para OpenClaw.

## Inicio rápido

1. Abre `OpenClaw_RAG_Basico_Colab.ipynb` en Google Colab.
2. Ejecuta todas las celdas.
3. Opcional: configura el secreto `GEMINI_API_KEY` en Colab para generación con LLM.
4. Descarga el ZIP de la skill que produce el notebook e instálalo en tu workspace de OpenClaw.

**Nota:** El notebook no ejecuta OpenClaw dentro de Colab; prepara una skill para un host OpenClaw real. Sin API key, el resultado es búsqueda semántica más respuesta extractiva.

Referencia: https://docs.openclaw.ai/tools/creating-skills
